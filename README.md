# Atmosphere Enhancements

This BepInEx mod adds cave and mineshaft ambience for MineMogul with two audio layers:

- Ambient Beds
  - longer background ambience tracks with fade-in and fade-out
- Incidental One-Shots
  - sparse short detail sounds such as drips, creaks, rock ticks, metallic clinks, and subtle wind

Quiet mode remains the authority for whether ambience is allowed to play. If nearby non-footstep world audio is too loud, new ambience is suppressed, and active ambient beds can still fade out after sustained noise.

## Runtime audio workflow

1. Put packaged default files in `Resources/Audio/DefaultAmbient` before building if you want them embedded in the DLL.
2. On game startup, packaged files are exported to `AmbientAudio` next to the plugin DLL.
3. The mod loads ambient beds from `AmbientAudio/Beds`.
4. The mod loads incidental one-shots from `AmbientAudio/OneShots/<Category>`.
5. Legacy supported audio files placed directly in `AmbientAudio` still load as ambient beds.

Runtime folder example:

```text
BepInEx/plugins/AtmosphereEnhancements/AmbientAudio/
|-- Beds/
|-- OneShots/
|   |-- Drips/
|   |-- Creaks/
|   |-- RockTicks/
|   |-- MetalClinks/
|   `-- Wind/
`-- <legacy loose beds still supported>
```

## Build

```powershell
dotnet build ".\AtmosphereEnhancements.csproj" -c Release
```

Output DLL:

- `bin\Release\net472\AtmosphereEnhancements.dll`

## Config

Config file (auto-generated by BepInEx):

- `BepInEx/config/com.main.atmosphereenhancements.cfg`

Important settings:

- `General.Enabled`
- `General.AmbientVolume`
- `Timing.*`
- `QuietMode.OnlyStartWhenQuiet`
- `QuietMode.QuietThresholdToStart`
- `QuietMode.StopIfNoLongerQuiet`
- `OneShots.EnableOneShots`
- `OneShots.OneShotMinDelaySeconds`
- `OneShots.OneShotMaxDelaySeconds`
- `OneShots.OneShotBaseVolume`
- `OneShotCategories.*`
- `OneShotWeights.*`
