# Atmosphere Enhancements

This BepInEx mod plays ambient audio tracks at intervals.

## Key behavior
- Plays random ambient tracks with random silence gaps between them.
- Supports long tracks (streaming load mode is enabled by default).
- Ambient source is 2D so it can stay audible over footsteps.
- Start can be gated by nearby non-footstep game audio loudness.
- Optional: if nearby audio stays loud (for example machines), currently playing ambient can fade out and stop.

## Audio workflow
1. Put packaged/default files in `Assets/DefaultAmbient` before building (optional).
2. On game startup, packaged files are exported to `AmbientAudio` next to the plugin DLL.
3. The mod loads ambient tracks from that runtime `AmbientAudio` folder.
4. You and other players can drop in extra `.ogg/.wav/.mp3/.aif/.aiff` files there.

Runtime folder example:
- `BepInEx/plugins/AtmosphereEnhancements/AmbientAudio`

## Build
```powershell
dotnet build ".\AtmosphereEnhancements\AtmosphereEnhancements.csproj" -c Release
```

Output DLL:
- `AtmosphereEnhancements\bin\Release\net472\AtmosphereEnhancements.dll`

## Config
Config file (auto-generated by BepInEx):
- `BepInEx/config/com.main.atmosphereenhancements.cfg`

Important settings:
- `General.Enabled`
- `General.AmbientVolume`
- `Timing.*`
- `QuietMode.OnlyStartWhenQuiet`
- `QuietMode.QuietThresholdToStart`
- `QuietMode.StopIfNoLongerQuiet`
